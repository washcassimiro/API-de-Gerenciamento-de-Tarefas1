# API de Gerenciamento de Tarefas

API RESTful desenvolvida em Python para a atividade prática da disciplina de **Arquitetura e Desenvolvimento de APIs** do Centro Universitário Internacional UNINTER.

## Descrição do Problema
A aplicação consiste em um sistema de gerenciamento de tarefas (To-Do List) que permite registrar, consultar, filtrar, atualizar e excluir tarefas com persistência em banco de dados relacional.

## Tecnologias Utilizadas
* **Linguagem:** Python 3.14
* **Framework:** FastAPI
* **ORM:** SQLAlchemy
* **Banco de Dados:** SQLite
* **Servidor ASGI:** Uvicorn
* **Validação de Dados:** Pydantic
